# CKW SMART GUARD — MVP

ต้นแบบเว็บแอปสำหรับหน้าจอเจ้าหน้าที่ของ CKW SMART GUARD เปิดใช้งานได้โดยดับเบิลคลิก `index.html` ในเว็บเบราว์เซอร์ ไม่ต้องติดตั้งโปรแกรมเพิ่มเติม

สำหรับเปิดบนโทรศัพท์ใน Wi-Fi เดียวกัน ให้ทำตาม [MOBILE-ACCESS.md](MOBILE-ACCESS.md)

## สิ่งที่พัฒนาแล้ว

- หน้าล็อกอินต้นแบบและโครงสร้างสิทธิ์สำหรับเจ้าหน้าที่
- Dashboard, คิวเหตุการณ์, หน้าตรวจสอบ/ปิดเหตุการณ์, Heatmap, รายงาน, สถานะอุปกรณ์ และหน้าตั้งค่า
- รับและจัดการเบาะแสในโหมดต้นแบบ
- หน้าแจ้งเบาะแสสาธารณะ ([report.html](report.html)) และหน้าติดตามสถานะด้วยรหัส ([track.html](track.html))
- ส่งต่อเบาะแสจากหน้าสาธารณะเข้าสู่มุมมองเจ้าหน้าที่ด้วย browser storage สำหรับการสาธิตบนเครื่องเดียวกัน
- ป้องกันการอ้างผล AI เป็นคำตัดสินอัตโนมัติในส่วนติดต่อผู้ใช้
- ข้อมูลตัวอย่างอยู่ในหน่วยความจำของเบราว์เซอร์ เพื่อใช้สาธิต flow เท่านั้น

## สิ่งที่ต้องทำก่อนใช้งานจริง

โปรเจกต์นี้ยังไม่มี backend หรือการเชื่อมต่อบริการจริง เพราะเครื่องพัฒนายังไม่มี Node.js หรือ Python runtime ติดตั้งอยู่ จึงต้องเพิ่มระบบดังต่อไปนี้ก่อนนำร่อง:

1. Backend ที่ยืนยันตัวตนด้วย SSO/MFA และ RBAC
2. ฐานข้อมูลเข้ารหัส, object storage ภาพหลักฐาน, retention policy และ audit log ที่แก้ไขย้อนหลังไม่ได้
3. API ingestion จาก YOLOv8, ESP32/IoT gateway และ IP Camera ที่ยืนยันตัวตนอุปกรณ์
4. LINE Messaging API โดยเก็บ token เป็น secret ไม่วางไว้ในหน้าเว็บ
5. หน้าสาธารณะรับเบาะแสที่แยกจาก dashboard และทำ privacy/threat-model review
6. การทดสอบการเข้าถึงตามบทบาท, false alarm, latency, precision/recall และ UAT กับครู

รายละเอียดเชิงสถาปัตยกรรมและ Roadmap อยู่ใน `CKW-SMART-GUARD-PLAN.md`.
